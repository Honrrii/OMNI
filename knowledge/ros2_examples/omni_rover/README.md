# omni_rover

Generated by OMNI Command.

## Mission

Design a ROS2-based autonomous mini rover named OMNI Rover. It should use a Raspberry Pi, two DC gear motors, a motor driver, ultrasonic distance sensor, IMU, camera module, battery pack, and 3D-printed chassis. Generate a ROS2 package plan with named nodes, topics, message types, publishers, subscribers, launch file plan, and starter files. Include hardware architecture, Fusion 360 chassis concept, risk matrix, validation checklist, Pluto critique, QaZ validation, export-ready artifacts, and a revised final blueprint. Do not assume final motor torque, battery current capacity, wheel diameter, chassis material, dimensions, or payload mass are known; list them as measurements Henry must confirm before hardware testing.

## Nodes

- motor_control_node: Controls the DC motors for movement.
- distance_sensor_node: Reads data from the ultrasonic sensor.
- imu_node: Collects data from the IMU.
- camera_node: Captures images from the camera module.
- navigation_node: Handles navigation logic.

## Build

    colcon build --packages-select omni_rover
    source install/setup.bash

## Launch

    ros2 launch omni_rover omni_rover_launch.py
